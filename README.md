 🎉 Teachers’ Day Message Card

A personalized digital Teachers’ Day message card created using HTML, CSS, and JavaScript to express appreciation and gratitude to a teacher.

This project was customized with a personal message, teacher photo, audio message, and an elegant card design.

 📖 Features

* 🎨 Customized Design – Uses a clean and elegant green-themed design with a soft gingham background.
* 💬 Personalized Message – Includes a heartfelt Teachers’ Day message for Sir Randy.
* 🖼️ Personalized Teacher Photo – Uses a customized photo of the teacher.
* 🎵 Audio Message – Includes a personalized audio file with Play/Pause functionality.
* ✨ Interactive Button – JavaScript controls the audio playback and changes the button between Play and Pause.
* 📱 Responsive Layout – Designed to display properly on different screen sizes.

 🛠️ Technologies Used

* HTML5 – Used to create the structure and content of the message card.
* CSS3 – Used for the colors, fonts, spacing, background, and overall card design.
* JavaScript – Used to add audio playback and Play/Pause interaction.

 🚀 How to Use

1. Download or clone the project.
2. Make sure all project files are inside the same folder.
3. Open `index.html` in a web browser.
4. Read the personalized Teachers’ Day message.
5. Click the **Play Message Audio** button to play the audio.
6. Click the button again to pause the audio.

 🎯 Customization

The project can be customized by editing the following files:

* `index.html` – Change the teacher's name, message, image, and audio file.
* `style.css` – Change the colors, fonts, spacing, background, and card design.
* `script.js` – Modify the Play/Pause audio interaction and other JavaScript features.

📁 Project Files

* `index.html` – Main webpage and message card structure
* `style.css` – Design and styling
* `script.js` – JavaScript interaction
* `Randy.jpg` – Personalized teacher photo
* `songforyou.mp3` – Personalized audio message
* `README.md` – Project description and instructions

💡 Purpose

This project was created as a school activity to practice basic HTML, CSS, and JavaScript skills while creating a meaningful digital Teachers’ Day greeting.

It is intended as a digital appreciation card for a teacher who has provided guidance and support throughout the student's college journey.
